2. SYSTEM DATA FLOW & ACTIVE LEARNING LOOP
--------------------------------------------------------------------------------
[User Input: Garment Image + Context Note]
   │
   ├── 1. Client-Side Image Quality Pre-Flight Assessment (Resolution & Brightness)
   ▼
[FastAPI Backend (/api/predict)]
   │
   ├── 2. Request Validation & Temporary Raw Image Caching in data/uploads/
   ├── 3. Image Preprocessing (224x224, ImageNet Mean/Std Normalization)
   ├── 4. MobileNetV2 TorchScript Feature Extraction & Softmax Inference
   ├── 5. Decision Gate (Confidence >= 70%, Top-2 Margin >= 20%, Non-Fabric Check)
   ├── 6. Fabric Knowledge Base & Scientific Care Profile Synthesis
   ├── 7. SQLite Database Persistence (predictions table with payload + note)
   ▼
[React + TypeScript Platform]
   │
   ├── Care Profile & Probability Distribution Breakdown
   ▼
[User Active Learning Verification (/api/feedback)]
   │
   ├── "Yes, it's Cotton" -> Saved to data/train/cotton/user_<timestamp>.jpg
   └── "No, it's Silk"   -> Saved to data/train/silk/user_<timestamp>.jpg
   │
   └── Periodic Training Script (backend/scripts/train.py) retrains on expanded corpus!

3. RUN INSTRUCTIONS
--------------------------------------------------------------------------------
Option A: One-Click Quick Start (Windows)
   Double-click `run-laundryai.bat` in the project root.

Option B: Manual Terminal Startup
   Window 1 (Backend):
     cd backend
     .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

   Window 2 (Frontend):
     cd frontend
     npm run dev

   Access:
     - Web UI:  http://localhost:5173
     - API Docs: http://127.0.0.1:8000/docs

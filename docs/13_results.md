# V. RESULTS AND DISCUSSION

This section reports the shipped combo G ensemble evaluation artifact in `backend/backend/models/fabric_ensemble.manifest.json` (model version `ensemble-g-20261108`, evaluated 2026-11-08). The held-out clean test set contained 277 images across cotton, polyester, denim, wool, and silk, after the leaked non-fabric copies were excluded via the denylist (see below). A separate held-out real-photo set of 513 whole-garment product photos (TextileNet, never trained on) and its 513 dimmed copies measure expected phone-scan performance. Results are for these datasets and must not be represented as universal real-world performance.

The earlier MobileNetV2-only figures (79.43% on 282 images) are superseded and must not be quoted: the 282-image set still contained the 5 non-fabric test images that were byte-identical copies of train images, and the single model has since been replaced by the combo G ensemble.

## Discussion

The combo G ensemble achieved 84.84% accuracy and 0.8473 macro F1-score on the 277-image held-out clean test set, with 92.66% accuracy on the answers it accepts at the 0.55 confidence / 0.10 margin gates (21.3% of test images fall below the gates and return `unknown`). Denim produced the strongest F1-score (90.62%), while polyester produced the lowest (74.77%), and errors occur primarily between visually similar categories — cotton↔polyester and cotton→denim — rather than uniformly across all classes. On the held-out real-photo set the ensemble scores 68.03%, and 65.11% on dimmed copies: the gap to the clean-test figure is the honest expectation for everyday phone scans, and it is a large improvement on the superseded v1 single model, which scored 83.03% clean but only 8.19% on real photos. The non-fabric class has no held-out images, so non-fabric rejection remains unmeasured until fresh non-fabric photos are collected.

The deployed system couples the model output with a structured care knowledge base. Therefore, washing, drying and ironing guidance is not presented as a direct CNN prediction; it is a transparent rule-based recommendation retrieved after the fabric category is predicted. These results support use as a planning and decision-support prototype. Additional independently collected garment images, blend labels, real-world lighting tests and user-study responses are required before making stronger generalization or usability claims.
